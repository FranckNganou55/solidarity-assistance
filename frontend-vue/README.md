# Interface Vue.js

Interface web responsive de Makénéné Solidarité, construite avec Vue 3, Vue Router, Pinia et Vite. Elle consomme l’API Laravel via `/api` et reprend le thème institutionnel et les logos de l’association.

Depuis la racine, démarrer l’ensemble avec `./scripts/start-local.ps1`. Vite écoute sur `http://localhost:3000` et relaie les appels API vers `127.0.0.1:8082`.

Pour vérifier la compilation : `npm run build`.
